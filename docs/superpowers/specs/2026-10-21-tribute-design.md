# 进贡还贡（V1.5 规则说明与实现设计）

**日期:** 2026-10-21
**父项目:** 掼蛋网页版（见 `2026-10-18-guandan-webgame-design.md`）
**依据:** 《淮安掼蛋竞赛规则》/《江苏省掼蛋竞赛简易规则（2017 版）》
（中文维基「掼蛋·贡牌」与英文维基「Guandan·Tribute / Subsequent Hands」两处互证）
**状态:** 规则已核对官方口径；引擎先行，UI 与联机下一轮接上

## 为什么之前写错了

第一版设计稿按「三游、四游各交一张给对手队头游」写，那是想当然。官方口径是：

- **下游方**（第四名下家所在的一队）给**上游方**（头游所在的一队）进贡；
- 上游方**还要还牌**：回给下游方一张 **2–10** 的牌；
- **还牌后第一圈由下游方领出**（不是头游领出）。

这两条决定了整个流程，也是下面状态形状的依据。

## 采纳的规则（官方口径）

1. **第一副牌没有进贡**（整场第一局不贡）。
2. **谁进贡**：上一局的**下游**（第四名）。
   **双下游**（三游与四游同队）时，这两人**各**进贡一张。
3. **贡什么**：手里点数最大的牌（官方另有一条「红心级牌不能上贡」，
   我们还没做逢人配，级牌不作特殊牌，暂不适用）。
4. **给谁**：
   - 普通情况：下游 → **头游（上游）**；
   - 双下游：两人各交自己最大的一张，**大的给头游，小的给二游**（点数相同则按顺时针分配）。
5. **还牌**：收贡方回一张 **点数不大于 10** 的牌给对方。
   （我们牌序里 2 记作 18，所以还牌实际是 3–10；规则上界仍写作 10。）
6. **抗贡**：进贡者手里有**双王（大小王各一）**或**天王炸（四张王）**时可以不进贡。
   此时**头游领出**。
7. **谁领出**：**下游**（双下游时是贡牌较大那位）领出新一局的第一圈。
8. **牌数**：进贡的牌不进牌堆，直接进收贡者新局的手牌；还牌的牌从收贡者新局手牌里出，
   进贡者新局手牌因此少拿一张、收回一张——**每家仍是 27 张**。

## 明确不做（本轮不写）

- **逢人配**（红心级牌当万能牌）与「级牌大于 A」的牌序：另一条规则线，另开一轮。
  现在的牌序是「2 最大」（跑得快口径），与官方淮安口径不同，此处只标注，不在本轮改。
- **报牌**（剩 ≤10 张要报数）：我们 UI 有「报牌」提示，但不做强制声明。
- **冲关失败**（A 级连三局上下游）等延伸规则。

## 状态形状

```ts
export type TributeState = {
  order: Seat[]              // 上一局名次（头游 → 四游）
  givers: Seat[]             // 进贡者（下游；双下游时三游+四游）
  to: Record<number, Seat>   // 进贡者 → 收贡者
  given: Record<number, string | null>  // 已交贡牌 id；null = 抗贡；undefined = 未动
  cards: Record<number, Card>           // 贡牌实体
  anti: Seat[]               // 抗贡的座位
  step: 'give' | 'return'    // 交贡 / 还贡
  returnees: Seat[]          // 还要还牌的收贡者
  returnTo: Record<number, Seat>  // 还牌给谁
  returned: Record<number, string | null>
  leader: Seat               // 新一局谁领出
  seed: number
}
```

## 引擎接口

```ts
export function newTributeRound(prev: GameState, opts?: { seed?: number }): GameState | null
export type Action = ... | { kind: 'give'; seat: Seat; card?: string }  // card 省略 = 抗贡
```

- `newTributeRound`：整场结束（打过 A）返回 null；否则算出进贡者/收贡者，
  复制上一局**旧手牌**（进贡者要看到自己手里最大那张），`phase = 'tribute'`。
- `give` 动作（step='give'）：进贡者交牌（牌在自己手里）→ 记到收贡者名下；
  牌交完（或抗贡）后引擎发新局（进贡牌进收贡者手牌，进贡者少拿一张），
  然后进入 step='return' 让收贡者还牌。
- `give` 动作（step='return'）：收贡者还一张 ≤10 的牌 → 交给对应的进贡者。
- 还牌结束 → `phase = 'playing'`，`turn` = `leader`（下游 / 贡牌较大者 / 抗贡时头游）。

## UI 与联机（下一轮）

- 牌桌在 `phase === 'tribute'` 时切进贡视图：
  进贡者看到「把你最大的一张交给对方头游」+ 选牌 +（有双王时）「抗贡」；
  还贡者看到「还一张 10 以下给下游」+ 选牌；其他人看到「等待 X」。
- AI：交自己最大的牌；有双王/天王炸就抗贡；还牌时还自己最小的 ≤10 牌。
- 联机：`tribute` 进 `SerializedState`，房主权威跑引擎，客人渲染镜像。
