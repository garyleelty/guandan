# 一键理牌（手牌排序切换）设计

**日期:** 2026-10-18
**父项目:** 掼蛋网页版（见 `2026-10-18-guandan-webgame-design.md`）

## 目标

手牌 27 张时，点数降序排列不便于察觉同花顺。增加「理牌」按钮，一键在两种排列间切换：

- **点数模式（默认）**：引擎现有顺序——点数降序，同点按 ♠♥♣♦。
- **花色模式**：同花聚拢——大小王置首，随后按花色分组（♠ → ♥ → ♣ → ♦），组内点数降序，便于扫出同花顺。

## 设计

### 纯函数（core 层，TDD）

`src/core/cards.ts` 新增：

```ts
export function sortBySuitGroups(hand: Card[]): Card[]
```

- 主键：王（suit -1）在前 → 花色 0/1/2/3。
- 次键：组内点数降序；同点同花色（两副牌重复）保持输入相对顺序。
- 不修改入参，返回新数组。

引擎状态、网络传输的手牌顺序保持原序；排序仅发生在渲染前。

### UI 层

- `Table.tsx` 本地状态 `handMode: 'rank' | 'suit'`，初始 `'rank'`。
- 渲染前按模式排序手牌副本；选中集合按 card id 记录，重排不影响选中。
- 控制栏（「我的牌 × 张 · 第 n 级 | 出牌 | 过 | 🔊」行）加「理牌」按钮，点击切换模式；按钮**始终可见**（观察期也可理牌整牌）。
- 仅当前对局内记忆（组件状态），不写 localStorage；刷新/新局回到点数模式。
- 卡片节点 key 为 card id，React 复用节点；为卡片容器加 `margin-left .3s` 过渡使位移平滑。

### 不做（YAGNI）

- 不做三态/升降序循环。
- 不做持久化偏好。
- 不改引擎手牌顺序，不参与 P2P 同步。

## 测试

- `cards.test.ts` 新增 `sortBySuitGroups` 用例：
  1. 同花色全部相邻；
  2. 大小王置首；
  3. 花色顺序 ♠→♥→♣→♦；
  4. 组内点数降序；
  5. 空数组/单张不崩。
- 手动验收：单机局点「理牌」截图（花色聚拢），再点切回。
