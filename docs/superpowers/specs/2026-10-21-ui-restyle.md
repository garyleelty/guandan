# UI 改版：夜桌（True-black flat）

**日期:** 2026-10-21
**父项目:** 掼蛋网页版（见 `2026-10-18-guandan-webgame-design.md`）
**方向:** `design-taste-frontend` / `draw.mjs --app --style true-black-flat`（seed 758630644）

## 为什么换方向

旧版是「Apple 浅色 + 磨砂玻璃 + 蓝色渐变按钮」，inspector 判定 4 FAIL：
渐变按钮、悬浮重阴影、无 h1、大面积空地。牌是这张桌上唯一的亮物，桌面本该是暗的——
牌与桌的对比才是掼蛋的本体。因此把「Apple 浅色」换成 **True-black flat**（暗色真黑）：
桌面 = 暖近黑，卡片 = 唯一亮面，琥珀色只落在数据上。

**琥珀色（accent）只出现在数据上**：级牌数字、我方座位标记、炸弹特效、当前轮次提示。
按钮、导航、标签一律不用琥珀色——主按钮是**反色白底黑字**。

## 产品自己的脸（Its face）

1. **牌桌底色取掼蛋自己的温度**：暖近黑 `#0e0d0c`（不是纯黑，不是藏青），卡片 `#ffffff` 浮在桌上。
2. **唯一数据色取掼蛋世界里的金色**：琥珀 `#f2b33d` = 级牌徽标 / 炸弹 / 我方座位。
3. **签名元素：级牌阶梯（Level ladder）**——13 级（2…A）的一格一格轨道，
   两队各一条，头游升了几级直接看得见。出现在顶栏（对局中）与结算面板（升级后）。

## 屏幕结构

### 牌桌（Table，主屏）

- **顶栏 48px**，一条 1px `--color-line` 下沿：
  左 = 产品标记 + 「掼蛋」（h1，18px）；中 = 级牌（一张小白牌）+ 两队的级牌阶梯；右 = 房间/单机范围 + 音效开关（16px SVG 图标，非 emoji）。
- **座位**：上=我方搭档，左=上家，右=下家。每家一个 `--color-surface` 面板：
  名字 + 队伍点（我方=琥珀点，他方=中性点）+ 角色 + 剩牌数（tabular 数字）+ 报牌（≤2 张，琥珀 chip）
  + 名次（头游/二游…，中性 chip）。轮到的座位：面板描边转琥珀。
  对手面板下方一排**牌背**（最多 10 张 + “+N”），张数即数据。
- **记录条**（座位下方一条 1px 上下边线）：左 = 出牌记录（横向 chip 流，滚动的最近一手）；
  右 = 记牌器「未见牌面」（每个已出现过的点数还可能剩几张 + “余 N 个点数未现”）。
- **中央牌区**：本轮出的牌（真实牌面小卡）+ 一行说明「对家 · 炸弹」；空时显示「等待X领出」。
- **我的手牌**：白牌一排（按可用宽度收紧重叠，27 张不撑破页面），选中上抬 8px 并压琥珀描边，压不过的牌降到 40% 不透明度。
  顶部操作条：**出牌**（反色主按钮）/ **过**（描边）/ **理牌**（点数 ⇄ 花色）。
- **炸弹特效**：纯黑横带 + 琥珀大字「炸弹」「天炸」，无渐变、无光晕。

### 大厅（Lobby）

- 桌面两栏（≥768px）：左 = 标记 + h1「掼蛋」（20px）+ 一行副标题 + 昵称输入（标签在上，40px 高，1px 描边）
  + 三个入口（**单机开局** 唯一反色主按钮 / 创建房间 描边 / 通过链接加入 文字按钮）；
  右 = 面板：门面上的三张牌（2♠ A♥ 大王，真实牌面）+ 「玩法速览」5 条真实规则。
- 无玻璃、无大圆角白卡、无渐变、无人形 emoji。

### 房间（Room）

- 主体一块面板：房号（tabular 大字，琥珀——数据）+ 复制链接（只读输入 + 复制按钮）；
  四个座位行（本座/右家/对家/左家 + 虚位/AI/玩家 + 补位/移除动作，1px 分隔线）；**开始对局**（反色主按钮）。
- 客人侧：输入房码（等宽大字）、连接中断文案 + 返回大厅。

### 结算（覆盖在牌桌上）

- 面板：标题（升级/夺局）、四名次列表、级牌阶梯（含 2…A 刻度标签）、再来一局（主）/ 返回大厅（描边）。

## 规则

- 不加玻璃、不加渐变、不加 emoji、不加阴影（浮层除外）、不用装饰性图标盒。
- 数字用 `tabular-nums`；正文 14px，小字 13px，标题 18–20px——没有第 5 个字号。
- 一个屏幕一个反色主按钮。
- 动效只做反馈：牌落下、选中上抬、炸弹震屏；不入场动画。

## 与牌面/方向的偏差（记录在案）

- **字体**：牌面说 Inter，但 Inter 没有中文字形；改成 `Inter`（拉丁与数字，Google Fonts 真实加载）
  + `PingFang SC`（中文）并列，中文回退到系统黑体。inspect 的 `font-not-dealt` 因此消失，中文仍是黑体。
- **emoji**：花色 ♠♥♦♣ 与 🔊 一律换成矢量 SVG（`src/ui/Suit.tsx`、`src/ui/Mark.tsx`），
  既避免 inspect 的 emoji 判定，也让各系统渲染一致。
- **等宽字**：房码与分享链接保留 `font-mono`——app 规则允许 ID/URL 用等宽字。
- **暗色不藏青**：桌面用暖近黑 `#0e0d0c`，不是藏青/石板灰。
